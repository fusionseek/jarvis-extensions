# 手机应用

扫描 USB 连着的安卓手机上装的全部应用：**包名、大小（安装包 / 数据）、应用名与图标**。
看中哪一个，点行尾的按钮把包名交给 Jarvis 内置的「APK 扫描」或「数据导出」，接着做那边的事。

## 入驻哪些域

manifest v2（SDK 2.4）按域声明：

| 域 | 在哪里 |
| --- | --- |
| 工具箱 | 工具箱目录里一行「手机应用」；点开是面板里那一页（设备、搜索、范围与排序、应用清单） |

没有窗口、指令、设置与服务；`inbox: false`——它不投 Inbox、不弹横幅。

## 它要哪些授权，为什么

两项。第一次进入这一页时 Jarvis 弹一次授权屏；之后可以在 `设置 › 扩展 › 手机应用` 里逐项撤销。

| 能力 | 档位 | 用来 | 宿主替你拦住的 |
| --- | --- | --- | --- |
| `android.apps.read`「读取手机上的应用」 | 中 | 列连着的设备；列一台设备上装的应用与大小；一屏一屏读应用名、版本与图标 | 宿主经**它自己的** adb 跑它写死的那几条命令，扩展只给设备序列号与包名；读名字与图标时安装包临时拉到本机、读完即删 |
| `android.tools.open`「交给 APK 扫描 / 数据导出」 | 低 | 行尾那两颗按钮：把包名交给内置工具 | 只是打开那个工具、把包名填好；**开始仍由你在那边按** |

它**不跑任何命令**（没有 `process.run`）、**不读文件**（没有 `files.read`）、**不联网**（没有 `network.https`）：
adb 与 aapt2 只在 Jarvis 里跑，跑什么由 Jarvis 决定，扩展改不了一个参数。

关掉 `android.apps.read`：页面是一屏「没有读取手机应用的授权」加一颗「授权」，不碰 adb。
关掉 `android.tools.open`：清单照常；按行尾按钮时就地再问一次，拒了画一张说明加一颗「授权」。

## 宿主替它读什么

| 调用 | 什么时候 | 一次多少 |
| --- | --- | --- |
| `android.devices()` | 进入这一页、点「重新扫描」 | 1 次 |
| `android.apps({ serial, scope })` | 选好设备之后、换设备、换「用户应用 / 全部」、重新扫描 | 1 次 |
| `android.appDetails({ serial, packages })` | 清单画出来之后，按屏幕从上往下 | 每次至多 8 个包、**同一时刻只有一次在途** |
| `android.openTool({ tool, package })` | 你按下行尾的「APK 扫描」或「数据导出」 | 1 次 |

读应用名与图标要拉安装包、跑 aapt2，每个包几百毫秒到几秒，所以它**只读画出来的那些行**：先是第一页 40 行，
滚到底（或按「再列 N 个」）再读下一页。搜索框按名字找不到还没轮到的应用时，空结果那一屏会说「已读 x / y」，
并给一颗「读全部应用名」——只有你按了它才往后读整张表。读到的名字与图标按「设备 + 包名」记在内存里，这一页关了再开还在；
「重新扫描」之后只重读安装包大小变了的（应用更新过）。

## 怎么用

1. 手机上打开「开发者选项 › USB 调试」，用 USB 连上 Mac；第一次连时手机会问「允许 USB 调试吗」，点允许。
2. 工具箱 › 手机应用。一台设备直接列；多台时「设备」那一行出一个下拉。
3. 「用户应用 / 全部」切范围，「按大小 / 按名称」切排序，搜索框按应用名或包名搜（不分大小写）。
4. 段标题右端是「N 个应用 · 共 X」；每一行是应用名（还没读到时是包名）、包名与大小——安装包与数据都知道时分开写。
5. 行尾 `shippingbox`「APK 扫描」/ `square.and.arrow.down`「数据导出」：面板切到那个工具，包名已经填好。

| 你看到 | 什么情况 | 怎么办 |
| --- | --- | --- |
| 没有连着的安卓设备 | adb 一台都没看见 | 用 USB 连上手机、打开 USB 调试，再点重新扫描 |
| … 还没允许这台电脑调试 | 手机上那个弹窗还没点 | 在手机上点「允许 USB 调试」，再点重新扫描 |
| 读不到设备 · 未找到 adb | Jarvis 找不到 adb | 装好 Android platform-tools（或在 Jarvis 设置里指好 adb），再点重新扫描 |
| 读不出应用名和图标 | 宿主那边读安装包失败（例如没有 aapt2） | 包名与大小照常列出；装好 aapt2 后按「重试」 |
| 大小读不出 | 设备不报这个应用的大小（老系统、厂商改过） | 它不算进总数，页面底下会说有几个 |

## 已知边界

- **要 Jarvis 3.2.2 及以上**（`android.apps.read` / `android.tools.open` 与 `row` 的图标图随 3.2.2 首次发布）：manifest 的
  `minimumJarvisVersion` 是 `3.2.2`，更早的宿主在商店里看到「需要 Jarvis ≥ 3.2.2」；绕过去调用会得到 `capability.unknown`。
- **交给内置工具时只交包名**：「APK 扫描」「数据导出」用它们自己选着的那台设备。连着多台手机时，到那边确认是同一台。
- 清单至多展开到 400 行（一次画面的节点上限是 500）；「全部」里系统应用很多的手机会碰到，页面说一句，用搜索缩小范围。
- 按名称排时，还没读到名字的行（标题是包名）排在有中文名的那些后面；名字一批一批读到，顺序会跟着变。
- 不卸载、不停用、不清数据、不导出安装包：这一页只读。要做后续的事交给「APK 扫描」「数据导出」。
- 图标是宿主颁发的临时图片句柄，只在这一次会话里有效；面板关掉、换到别的扩展之后要重读。

## 开发

```bash
npm run build          # → dist/extension.js（提交进仓库）
npm run check          # tsc --noEmit
npm test               # model.test.mjs（纯函数）+ page.test.mjs（对着 dist 跑，设备一侧是 SDK 的 fakeAndroid()）
npm run validate       # schema + 跨字段规则 + 产物
```
