# 菜单栏管理

把用不着的菜单栏图标收起来。点一下「‹」露出来，指针离开一会儿自己收回；最不常用的放进「永远隐藏」，⌥ 点才出来。

## 怎么用

- 装上之后菜单栏上多三样东西（从右往左）：「‹」、一条竖线、再一条竖线。
- **按住 ⌘ 把图标拖到竖线左边**，收起时它就藏起来；拖到最左边那条竖线的左边，就进了「永远隐藏」。
- 点「‹」在露与收之间切换；⌥ 点连永远隐藏的一起露出来；右键开菜单。
- 设置 › 扩展 ›「菜单栏管理」：点菜单栏空白处显示（默认开）、悬停显示、滚动显示、自动收回秒数、是否启用永远隐藏段。
- 全局搜索或速记里 `/menubar`（`/菜单栏`）同样切换。
- 工具箱页列出每一段里有哪些图标、哪些被刘海挡住。

### 副栏（1.1）

- 设置里「隐藏的图标显示在」选「副栏」：点「‹」时菜单栏本身不动，在它下面弹一条副栏，画藏起来的图标（⌥ 点连永远隐藏的一起）。
  再点一下「‹」、点外面、按 Esc 都会收起；指针离开 15 秒自己收。
- 点副栏里的一颗：先把它所在的段露出来、等它进了屏幕、替你点开它；它的菜单一关就收回。弹的不是菜单（窗口、面板）时按「点过某颗图标」的规则，指针离开至少 20 秒再收。
- 在菜单栏里展开时，被刘海挡住、挤到刘海左边看不见的图标，会放进一条挂在竖线下面的副栏（设置里可以关）。
- 副栏里的图是图标露着时截下来的：启动收起之前、每次展开之后、为点开而露出时各截一次。没给截图授权、或 Jarvis 没有屏幕录制权限时画应用图标。

## 它是怎么做到的

Jarvis 只提供通用的东西：一个扩展可以在菜单栏上有几枚状态项，每枚可以定宽、可以只是一块空白；菜单栏上的指针事件；菜单栏上有哪些项。
「段」是这个扩展拼出来的：收起时把分隔竖线换成一块 10000 点宽的空白，它左边的图标就被挤出屏幕。扩展停用、卸载或出错时，Jarvis 把宽度复原，图标全部回来。

1.1 又用上三样通用的东西：截菜单栏上的项、点开菜单栏上的项、把弹窗锚在自己的状态项下面并让它随内容定宽。「点开藏起来的图标」
=「露出它的段 → 等它进屏幕 → 点开 → 等菜单关上 → 收回」，这一串是扩展拼的，Jarvis 只做其中「点一下」那一步。

## 性能

- 收着、没开悬停时，只有点击监听（和可选的滚动监听），只在你点、滚的时候醒；不挂任何定时器。
- 悬停监听只在开了「悬停显示」或图标露着、要等指针离开再收回时才装。
- Jarvis 读菜单栏只在它变了的时候：稳态读一次清单约 0.2 ms，不像有的菜单栏工具每秒把所有应用问一遍。
- 截图从不定时：只在上面那三个时刻、只截露着的隐藏段（一次约 50 ms + 每颗约 20 ms）。副栏打开时用的是 Jarvis 留着的那几张，不为了画副栏去动菜单栏。

## 能力

| 能力 | 做什么 |
|---|---|
| `menuBar.pointer` | 悬停、点空白处、滚动时露出隐藏的图标。只知道菜单栏那一条上的事 |
| `menuBarExtras.read` | 工具箱页与副栏列出每一段里的图标。需要 Jarvis 有辅助功能权限 |
| `menuBarExtras.capture` | 副栏与工具箱页画出图标的真实样子。需要 Jarvis 有屏幕录制权限；不给就画应用图标 |
| `menuBarExtras.control` | 点副栏里的一颗时替你点开它。需要 Jarvis 有辅助功能权限；个别应用不接受这种点法时会把指针挪过去点一下再放回原处 |

收起与显示本身不需要任何授权。
