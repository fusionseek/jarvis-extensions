# 发到手机

读一次剪贴板，经 Jarvis 快传把文字或链接推到已配对的手机上。

## 它要哪些授权，为什么

| 能力 | 用来 |
| --- | --- |
| 读取剪贴板 | 「读剪贴板」那颗按钮 |
| 查看快传状态 | 知道服务开没开、有没有手机接入 |
| 开启 / 停止快传 | 服务没开时那颗「开启快传」按钮；**不会在你没按的情况下打开** |
| 经快传发送 | 「发到手机」 |
| Inbox 卡片 | 发完留一张「已推到 iPhone」的卡，关掉面板也看得见；卡上「再发一次」 |

每一项都可以在授权弹窗里单独关掉；关掉的那一项对应的按钮会失效并给你一颗「授权」。

## 怎么用

1. 快传 → 开启，手机扫码接入（或在这个扩展里按「开启快传」再去快传面板扫码）。
2. 复制一段文字，进「发到手机」，按「读剪贴板」，按「发到手机」。
3. 手机页面的下行流里出现这条消息。

## 设置

- **去掉首尾空白**（默认开）。
- **发送前确认**（默认关）：开着时「发到手机」要按两次。

## 已知边界

- 只发文字与链接；发文件请用快传面板本身。
- 没有手机接入时照样能发，只是没人收到——与在快传面板里发一样。
- 不做发送历史；快传面板的活动流里有。
