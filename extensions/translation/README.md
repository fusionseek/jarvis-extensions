# 截屏翻译（`translation`）

按一下快捷键框选屏幕上任意一块，识别文字、合并段落、检测语言，再经 Google 翻译成你选的语言——
**译文就贴着选区原地弹出来**，眼睛不用离开刚才看的地方。框到的是一个词时，译文下面还有
读音与按词性分行的全部词义。也能把剪贴板里的文字或图片直接翻译。
它是这个平台「命令 + 页面 + 原地弹窗」模型的参考实现；底层只取 [Easydict](https://github.com/tisfeng/Easydict)
的 OCR + Google 翻译这一段核心逻辑，不做划词、不做多引擎。

## 三条命令

| 命令 | 默认快捷键 | 做什么 | 落点 |
| --- | --- | --- | --- |
| 截屏翻译 | ⌥⌘T | 框选 → OCR → 段落合并 → 语言检测 → Google | 译文贴着选区弹出（`popover`）；钉住或「在面板里打开」才进面板 |
| 截屏译文入剪贴板 | ⌥⌘O | 同上，但译文直接进剪贴板 | 什么都不弹，只留一条「已复制译文」横幅（`silent`） |
| 翻译剪贴板 | 无 | 剪贴板里是文字就翻文字，是图就先识字 | 面板里本扩展的页面（`panel`） |

快捷键在 设置 › 扩展 › 截屏翻译 里改。系统探测不到跨应用的冲突：按了没反应，多半是别的应用占着同一组键。

## 框到一个词：译文下面是一张词典卡

截一个词进来，只给排第一位的那个意思是不够的——`found` 还有创建、创立、缔造、勘查十几个义项，
只给「成立」等于替你选了一个。所以框到的是一个词时，译文下面还有：

```
成立！
[美] / found /            ♪
[v.]  创建; 创立; 成立; 创办; 建立; 缔造; 铸造; 创设; 铸成; 铸; 铄; 塑造; 建; 立; 设; 设立
[n.]  勘查; 勘探
```

- **读音**：英文是 Google 的**美式重拼**（`hello` → `həˈlō`），不是 IPA；中文是拼音，日韩是罗马音，
  标签会跟着变（美 / 拼音 / 罗马音）。旁边那枚朗读读的是**词条**——截到 `founded` 时它读 `found`。
- **词义一个都不省**，顺序是 Google 按使用频率排的，不重排。
- **词形不同会说出来**：截到 `founded` 时多一行「词条按 found 查」，免得那些词性看起来像在讲 `founded`。
- **什么时候出现由 Google 说了算**：`found!`、`  found  ` 都给，`Hello, world!`、`Save Changes`、
  `git commit -m` 一条都不给。这边不再用长度或正则判一次——判两次只会互相打架。
- **填了 API key 就没有这一块**：官方 Translation API v2 只翻译、不给词典，而为词典再偷偷发一个
  免费端点的请求等于背着你多打一次 Google。

## 原地弹窗里有什么

原文卡（可以改，改了按「翻译」重翻）、「原文语言 ⇄ 翻译成」一行（改哪一边都立刻重翻）、译文卡
（译文、词典、复制、朗读、再截一块）。弹窗 400 宽、按内容长高；Esc、点外面或指针离开 15 秒后关，翻译中不会自己收；
钉住则常驻；「在面板里打开」把同一份结果搬进面板。

## 它要哪些授权，为什么

| 能力 | 用来 |
| --- | --- |
| 截图 | 框选屏幕上要翻译的那一块（借用 Jarvis 自己的屏幕录制权限） |
| 识别图片文字 | 剪贴板里的图 |
| 读取剪贴板 | 「翻译剪贴板」 |
| 写入剪贴板 | 静默命令与「翻译完自动复制」 |
| 访问网络 | 只放行 `translate.google.com`、`translate.googleapis.com` 与 `translation.googleapis.com` |
| 系统横幅 | 静默命令完成（或失败）时的那一条 |
| 朗读 | 原文与译文的两颗小喇叭 |
| 全局快捷键 | 上面两条 |

每一项都可以在授权弹窗里单独关掉；关掉的那一项对应的按钮失效并给你一颗「授权」。
Jarvis 自己没有屏幕录制权限时，页面上会多一张「打开系统设置」的说明。

## 翻译从哪来

- **默认走免费端点**（`translate_a/single`），无需 key、也不需要 `tk` 签名。
  端点的限流是按 **(主机, client)** 算的：同一秒里 `client=gtx` 被 429，换一个 client 立刻 200。
  因此这里按顺序试四个候选，被限流就立刻换下一个：
  `translate.google.com/gtx`（Easydict 走的那一个）→ `translate.googleapis.com` 的
  `gtx` / `at` / `dict-chrome-ex`。一整轮都被拒才退避一次再扫一轮。
  它没有官方承诺，可能限流或改格式——失败时页面会写清是哪一种，并给「重试」。
- **填了 API key 走官方 Translation API v2**。key 是 `secret` 类型偏好：存在 Keychain、设置页遮罩显示、
  只有这个扩展自己读得到、不进日志。
- 原文本来就是目标语言时（截到的是中文、目标也是中文），改翻成「原文已是目标语言时」那一项选的语言。
- 国内需要代理：宿主的网络请求自动用系统代理设置。

## 设置

翻译成（默认简体中文）、原文已是目标语言时（默认 English）、识别语言（默认中英）、
Google API key（可选）、翻译完自动复制（默认关）。页面上的语言行只改这一次，不改设置。

## 已知边界

- 不做划词翻译：读其它应用的选中文本需要辅助功能权限，平台不给。
- 单次请求中文 1800 字符、其余 5000，更长的原文会分块逐次请求再按段落拼回；**分了块就没有词典**
  （第一块里的一个词描述不了整段话）。
- 弹窗跟着选区，不跟着鼠标；没截图的入口（翻译剪贴板）落在面板里。
- 代码通过类型检查、构建，与对着构建产物跑的 36 条端到端单测（`npm run test:extensions`）。

## 开发

```bash
npm run build          # → dist/extension.js（提交进仓库；本版 71 KB，上限 512 KB）
npm run check          # tsc --noEmit
npm test               # 对着 dist/extension.js 跑 test/*.test.mjs（宿主替身）
npm run validate       # schema + 跨字段规则 + 产物
```
