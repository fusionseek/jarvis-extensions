# 应用

让 Jarvis 的**全局搜索**（⌥Space，与默认页那条搜索栏同一个视图）认得这台 Mac 上的应用：

- 打字时，结果里在指令之后、最近打开之前出现匹配的应用（名字、英文名、拼音首字母 `wx` → 微信都认），⏎ 打开；
- 输入 `app` 空格进**应用视图**：按组排开的图标网格，对照 macOS 26「应用程序」那一屏；接着打字就在网格里筛；
- 在一枚图标上**按住** 0.5 秒进编辑态（同启动台）：能删的格左上角一枚 ✕，点了确认一次就移到废纸篓；**右键**「在访达中显示」。

工具箱里它那一页就是这些的**显示设置**：分组（分类 / 首字母 / 位置 / 不分组）、排序（名称 / 最近使用 / 最近添加）、
搜索结果里显示不显示应用、出几条、要不要系统应用，下面按这套设置预览每一组与个数。

## 入驻哪些域

manifest v2（SDK 2.5）按域声明：

| 域 | 在哪里 |
| --- | --- |
| 服务 `launcher.apps` | Jarvis 每次唤出全局搜索问一次 `catalog`：按设置分好组、排好序的应用 id，以及搜索结果里出不出、出几条。网格与搜索结果由 Jarvis 画 |
| 工具箱 | 工具箱目录里一行「应用」；点开是面板里那一页（设置 + 预览） |

没有窗口、指令；`inbox: false`。

## 它要哪些授权，为什么

一项。第一次进入这一页时 Jarvis 弹一次授权屏；之后可以在 `设置 › 扩展 › 应用` 里撤销。

| 能力 | 档位 | 用来 | 宿主替你拦住的 |
| --- | --- | --- | --- |
| `apps.read`「读取本机应用列表」 | 中 | 列这台 Mac 装的应用（名字、位置、分类、最近打开 / 添加时刻），排好交给全局搜索；页面上的预览 | 扫哪几处由 Jarvis 定，扩展给不了路径；**打开、在访达中显示、移到废纸篓只在全局搜索里由你点**，扩展做不了 |

它**不联网、不跑命令、不读文件**。设置存在扩展自己的存储里（`jarvis.storage` 的 `settings` 键），页面与服务读同一份。

关掉 `apps.read`：这一页的预览换成一屏「没有读取本机应用的授权」加一颗「授权」；全局搜索里没有应用，`app` 视图写一句「还没获准读取本机应用 · ⏎ 打开它授权」。

## 规则

| 规则 | 值 |
| --- | --- |
| 分类 | App Store 分类的中文名（宿主给 `categoryTitle`）；没有分类的归「其他」，排在最后 |
| 首字母 | 拉丁字母取本身，汉字按拼音（ICU 拼音序 + 分界字，多音字按 ICU 的读法），数字与符号归「#」，排在最后 |
| 位置 | 应用程序 → 我的应用 → 系统 → 其他位置 |
| 名称排序 | 先按首字母组、同组按拼音序：`Arc、备忘录、微信、Xcode` 交错排 |
| 最近使用 / 最近添加 | 新的在先；没有时刻的排在后面、再按名称 |
| 搜索条数 | 3 / 4 / 6（宿主上限 8） |

## 开发

```sh
npm run build   # 产物 dist/extension.js
npm run check   # tsc
npm test        # node --test：纯函数 + 整个扩展跑在 SDK 的宿主替身上
```
