# HTTP 状态码

查一个码：它是什么意思、为什么会出现、该怎么处理、原文在哪。

面板里输入 `404`、`超时` 或 `redirect`，一屏之内答完这四个问题；在终端或浏览器控制台里读日志时
按 **⌥⌘/**，Jarvis 读一次剪贴板、抓出里面的状态码，结果**贴着指针原地弹出来**——面板不动、
焦点不动，眼睛不用离开日志。

## 它做什么

| 你输入 | 你看到 |
| --- | --- |
| `404` | 详情：中文名、一句话语义、常见成因、怎么处理、相关的码、RFC 出处 |
| `超时` | 清单：408 / 504 / 522 / 524——中英文名与别名都在搜索范围里 |
| `4xx` | 这一类全部 28 个标准码 |
| `< HTTP/1.1 502 Bad Gateway` | 整行粘进来也认，直接开 502 |
| `999` | 一屏说明为什么没有：状态码只有 100–599 |

每条码上都标着工程师真正要看的两件事：**能不能重试**（可以 / 看 `Retry-After` / 重试没用）
与**默认可不可缓存**。

## 要哪些授权，为什么

三项，第一次进入时一次问完，随时可以在 `设置 › 扩展 › HTTP 状态码` 里撤销。

| 能力 | 档 | 拿来做什么 |
| --- | --- | --- |
| `clipboard.read` | 中 | **只在你按 ⌥⌘/ 的那一刻**读一次剪贴板，从里面找状态码。不订阅、不在后台盯着剪贴板 |
| `system.openURL` | 低 | 点「打开原文」时用默认浏览器打开 rfc-editor.org 或 MDN |
| `hotkeys.register` | 中 | 两条命令的全局快捷键（⌥⌘H · ⌥⌘/，可在设置里改） |

它**不写任何持久化存储**：查过什么只留在这一次会话里，面板收起来再打开还在，Jarvis 重启就没了。

**没有 `network.https`。** 62 个标准码与 12 个常见非标准码编在 `dist/extension.js` 里，
跟着扩展的版本走：一个查手册的工具没有理由拿到出网的权力。撤销 `clipboard.read` 之后
页面照常能用，只是 ⌥⌘/ 那条命令跑不起来——页面上会直说这件事，并给一颗「授权」。

## 怎么用

- **⌥⌘H** · 查状态码：把面板展开到这个扩展，并回到干净的一屏（按快捷键的人要的是重新查一个）。
- **⌥⌘/** · 解释剪贴板里的码：读一次剪贴板 → 原地弹窗。抓不到就说抓不到，不会静默。
- 清单里**指针停 320ms** 会浮出那条码的摘要；点一行展开完整一屏，详情屏左上角有「← 回到…」。
- **Esc** 清空搜索框（框是空的时候 Esc 收面板）。

设置页三项偏好：复制格式（`404` / `404 Not Found` / 整行含协议）、出处打开哪一边（RFC / MDN）、
搜索包含非标准码。搜索结果里那两枚 chip（「含非标准码」「只看 5xx」）是**会话值**：
从偏好初始化，清空搜索就回到偏好——它们是「这一次要看什么」，不是「我以后都想这样」。

## 已知边界

- **只收状态码。** `Cache-Control`、`Retry-After` 这些响应头，请求方法与 MIME 类型都不在表里。
- **非标准码只收最常撞见的 12 个**（nginx 5 个、Cloudflare 4 个、IIS 1 个、代理 1 个、外加玩笑码 418）。
  它们不在 IANA 注册表里，命中时界面上标着「非标准 · 来源」。把码敲全了直接查它们不受
  「含非标准码」那枚 chip 影响——你都把码敲全了。
- **表是静态的。** 注册表变了要等扩展发新版本，不会自己更新——这是不联网换来的代价。
- **⌥⌘/ 只读一次。** 它不监听剪贴板，因此复制之后必须按一次快捷键。
- **MDN 链接是按码拼出来的**（`/zh-CN/docs/Web/HTTP/Reference/Status/<code>`）；冷门码在 MDN 上
  可能没有对应页面，那时浏览器会落到 MDN 的 404 上。非标准码不给 MDN 链接，只给厂商文档。
- 语言：界面中文；搜索中英文都收（`timeout` 与 `超时` 命中同一批）。
- **要 Jarvis 2.0.1 或更新**：⌥⌘/ 那条命令的 `presentation` 是 `popover`，更早的宿主不认这个值，
  会把整份扩展库索引判为无效。
