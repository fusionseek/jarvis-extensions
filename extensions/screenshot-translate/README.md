# 截屏翻译

按一下快捷键框选屏幕上任意一块，识别文字、合并段落、检测语言，再经 Google 翻译成你选的语言。
也能把剪贴板里的文字或图片直接翻译。**它是这个平台「命令 + 页面」模型的参考实现。**

## 三条命令

| 命令 | 默认快捷键 | 做什么 | 面板 |
| --- | --- | --- | --- |
| 截屏翻译 | ⌥⌘T | 框选 → OCR → 段落合并 → 语言检测 → Google → 面板里看结果 | 展开到本扩展 |
| 截屏译文入剪贴板 | ⌥⌘O | 同上，但译文直接进剪贴板，弹一条「已复制译文」 | 不开 |
| 翻译剪贴板 | 无 | 剪贴板里是文字就翻文字，是图就先识字 | 展开到本扩展 |

快捷键在 设置 › 扩展 › 截屏翻译 里改。系统探测不到跨应用的冲突：按了没反应，多半是别的应用占着同一组键。

## 它要哪些授权，为什么

| 能力 | 用来 |
| --- | --- |
| 截图 | 框选屏幕上要翻译的那一块（借用 Jarvis 自己的屏幕录制权限） |
| 识别图片文字 | 剪贴板里的图 |
| 读取剪贴板 | 「读剪贴板」与「翻译剪贴板」 |
| 写入剪贴板 | 静默命令与「翻译完自动复制」 |
| 访问网络 | 只放行 `translate.googleapis.com` 与 `translation.googleapis.com` |
| 系统横幅 | 静默命令完成时的那一条 |
| 朗读 | 原文与译文的两颗小喇叭 |
| 全局快捷键 | 上面两条 |

每一项都可以在授权弹窗里单独关掉；关掉的那一项对应的按钮失效并给你一颗「授权」。

## 翻译从哪来

- **默认走免费端点**（`translate.googleapis.com/translate_a/single`，`client=gtx`），无需 key。
  它没有官方承诺，可能限流或改格式——失败时页面会写清是哪一种。
- **填了 API key 走官方 Translation API v2**。key 是 `secret` 类型偏好：存在 Keychain、设置页遮罩显示、
  只有这个扩展自己读得到、不进日志。
- 国内需要代理：宿主的网络请求自动用系统代理设置。

## 设置

翻译成（默认简体中文）、原文已是目标语言时翻成（默认 English）、识别哪些语言（默认中英）、
Google Cloud API key（可选）、翻译完自动复制译文（默认关）。

## 已知边界

- 结果显示在 Jarvis 的面板里，不是跟着鼠标的浮窗；面板展开在它原来的位置。
- 不做划词翻译：读其它应用的选中文本需要辅助功能权限，平台不给。
- 单次请求 4000 字符，更长的原文会分块逐次请求再按段落拼回。
- 这一版扩展要等 Jarvis 的扩展运行时（期 B）落地才跑得起来；代码已经通过类型检查、构建与 SDK 层的单测。
