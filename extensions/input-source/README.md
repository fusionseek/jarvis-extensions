# 输入法切换（`input-source`）

切到哪个应用，就自动换成你给它定的输入法：写代码的地方用 ABC，聊天的地方用拼音；网站也能单独定，比所在的浏览器优先。

## 入驻哪里

| 域 | 做什么 |
| --- | --- |
| 菜单栏 | 一枚键盘图标，旁边一个字（「中」「A」「あ」）表示此刻的输入法。点开：给**此刻这个应用**选输入法（各输入法 / 记住上次用的 / 无规则）；前台是浏览器时再给**此刻这个网站**选；以及暂停自动切换。点菜单栏图标不换前台，所以「此刻这个应用」就是你刚才在用的那个 |
| 工具箱 | 一页几张带色条的卡：顶上「此刻」的应用（右上角刷新）一行选项一点即定；下面每个输入法一张卡列出它的规则（「用 ABC」「用 微信输入法」……），每张右上角「+」从这台 Mac 装的应用里挑着加；点一行展开「换成」一点挪组，× 删掉；接着一张「网站」卡列出全部网站规则，右上角「添加网站」先选输入法再填网址（此刻在看的那一页一点即填）；第一次用时按应用分类推荐几条；最后一张是无规则的应用怎么办。前台是浏览器时，「此刻」卡上多一行当前网站 |
| 指令 | `切回上一个输入法`、`把此刻输入法定给当前应用`（`/input-source`）、`暂停或恢复自动切换`，都是静默的；默认不绑快捷键，在 设置 › 扩展 里自己绑 |
| 设置 | 无规则的应用（不动 / 记住上次用的 / 换成默认输入法）、切换时提示、提示的位置（悬浮球旁粘连闪现，默认 / 屏幕中间偏下）、手动切换时也提示、菜单栏图标旁显示当前输入法、暂停自动切换 |

## 要哪些授权、为什么

| 能力 | 档位 | 为什么 |
| --- | --- | --- |
| `system.activity` | 中 | 切到另一个应用的那一刻按它的规则换；只知道是哪个应用，不知道你在里面做什么 |
| `inputSources.read` | 中 | 列出你启用的输入法、知道此刻用的是哪一个、记下你上次在每个应用里用的那一个 |
| `inputSources.select` | 中 | 按规则换过去 |
| `hud.show` | 低 | 换过去的那一下闪一下：默认是「悬浮球旁」——输入法的图标放进悬浮球、名字贴在球下，停 2 秒一起收回（悬浮球展开或贴边藏起时改在屏幕中间偏下）；也可以选屏幕中间偏下的一枚小牌子，每次都在同一处。系统自带的输入法（ABC、简体拼音……）画成一枚字标键帽「A」「中」，与菜单栏上那个字一致；三方输入法用它自己的图标 |
| `apps.read` | 中 | 自己加规则时列出你装的应用、配上图标；第一次用时按 App Store 分类推荐（开发工具 → ABC，聊天 → 中文输入法） |
| `browser.activeTab` | 高 | 给网站定输入法时读一次你此刻在看的那一页，一点就加上；只在点「添加网站」时才问 |
| `browser.activeTab.watch` | 高 | 有网站规则时跟着前台浏览器换页，换到哪个网站就换成它的输入法；一条网站规则都没有时不订 |

不借任何系统权限。

## 会运行 / 读取什么

不运行任何命令、不联网。存在 Jarvis 本机库里的只有五样：规则（应用 → 输入法，至多 300 条）、网站规则（至多 200 条）、你上次在每个应用里用的输入法（手动换的那一下、或换走时用着的那一个；至多 300 个应用）、默认输入法、推荐卡点没点过「不用了」。读网页地址经系统的「自动化」授权，每个浏览器问一次。

**空闲不占 CPU**：没有定时器。只有切换前台、换输入法的那一刻宿主推一条事件过来；两条订阅让后台常驻，关掉菜单栏图标也照样在切。

## 怎么用

1. 打开工具箱里的「输入法切换」，点「允许」。第一次会看到一张推荐卡（「Xcode、终端 → ABC；微信 → 微信输入法」），点「全部添加」就定好了。
2. 要加别的应用：在「用 ABC」那一组右上角点「+」，挑一个应用。
3. 正在用的应用：顶上「此刻」那一排点一下；或者在任何应用里点菜单栏上的键盘图标选。
4. 网站：在「网站」卡右上角点「添加网站」，选输入法、填网址（或点此刻在看的那一页）；也可以在浏览器里点菜单栏图标，给此刻这个网站选。
5. 无规则的应用默认不动；想让它们记住你上次用的，在页面最下面把「无规则的应用」改成「记住上次用的」。不用先手动换一次：离开一个应用时用着的那个就记下了。
6. 面板钉着、切了别的应用：点「此刻」卡右上角的刷新。

## 已知边界

- **中文输入法里按 ⇧ 切到的英文模式**不是一个输入源：读不到也切不了，规则只能定到「微信输入法」，定不到「微信输入法的英文模式」。
- **不抢前台的浮层**（Spotlight、Alfred、Jarvis 的全局搜索）不算换了应用，不会按规则换。
- **网站规则**：只改地址、不改标题的单页应用跟不上（换了页没推过来）；Firefox 读不了地址；换标签要 Jarvis 有辅助功能权限，没有时只在切到浏览器时对一次。
- 和 Input Source Pro 这类切换器同时开着会互相改来改去，只留一个。
- 快速来回切应用时只认最后一次；切过去之后被别的东西改回去，0.3 秒后补切一次（只补一次，不和别的工具打架）。
- 菜单栏显示的是微信输入法、打出来却是英文：那是输入法自己的中 / 英模式（按 ⇧ 切的），不是换输入法，规则管不到。
- 上一版的「不管它」合进了「无规则」：存着的这类规则读出来当作无规则（默认「不动」时行为不变）。
- 需要 Jarvis ≥ 3.3.2（SDK 2.13：输入源、前台应用、提示（含悬浮球闪示）、卡片色条与持有订阅即常驻）。
