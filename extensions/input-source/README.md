# 输入法切换（`input-source`）

切到哪个应用，就自动换成你给它定的输入法：写代码的地方用 ABC，聊天的地方用拼音。

## 入驻哪里

| 域 | 做什么 |
| --- | --- |
| 菜单栏 | 一枚键盘图标，旁边一个字（「中」「A」「あ」）表示此刻的输入法。点开：给**此刻这个应用**选输入法（各输入法 / 记住上次用的 / 不管它 / 不写规则），以及暂停自动切换。点菜单栏图标不换前台，所以「此刻这个应用」就是你刚才在用的那个 |
| 工具箱 | 一页：顶上「此刻」的应用一排选项一点即定；下面按输入法分组列出全部规则（「用 ABC」「用 微信输入法」……），每组右上角「+」从这台 Mac 装的应用里挑着加；点一行展开「换成」一点挪组，× 删掉；第一次用时按应用分类推荐几条；最后是没写规则的应用怎么办 |
| 指令 | `切回上一个输入法`、`把此刻输入法定给当前应用`（`/input-source`）、`暂停或恢复自动切换`，都是静默的；默认不绑快捷键，在 设置 › 扩展 里自己绑 |
| 设置 | 没写规则的应用（不动 / 记住上次用的 / 换成默认输入法）、切换时提示、提示的位置、手动切换时也提示、菜单栏图标旁显示当前输入法、暂停自动切换 |

## 要哪些授权、为什么

| 能力 | 档位 | 为什么 |
| --- | --- | --- |
| `system.activity` | 中 | 切到另一个应用的那一刻按它的规则换；只知道是哪个应用，不知道你在里面做什么 |
| `inputSources.read` | 中 | 列出你启用的输入法、知道此刻用的是哪一个、记下你在每个应用里手动换过的那一个 |
| `inputSources.select` | 中 | 按规则换过去 |
| `hud.show` | 低 | 换过去的那一下，在文字光标旁闪一枚小牌子；读不到光标的应用（终端、部分网页）在指针旁边 |
| `apps.read` | 中 | 自己加规则时列出你装的应用、配上图标；第一次用时按 App Store 分类推荐（开发工具 → ABC，聊天 → 中文输入法） |

不借任何系统权限。Jarvis 有辅助功能权限时提示贴在文字光标下方，没有时在指针旁边——切换本身不受影响。

## 会运行 / 读取什么

不运行任何命令、不联网。存在 Jarvis 本机库里的只有四样：规则（应用 → 输入法，至多 300 条）、你在每个应用里最后一次手动换到的输入法（至多 300 个应用）、默认输入法、推荐卡点没点过「不用了」。

**空闲不占 CPU**：没有定时器。只有切换前台、换输入法的那一刻宿主推一条事件过来；两条订阅让后台常驻，关掉菜单栏图标也照样在切。

## 怎么用

1. 打开工具箱里的「输入法切换」，点「允许」。第一次会看到一张推荐卡（「Xcode、终端 → ABC；微信 → 微信输入法」），点「全部添加」就定好了。
2. 要加别的应用：在「用 ABC」那一组右上角点「+」，挑一个应用。
3. 正在用的应用：顶上「此刻」那一排点一下；或者在任何应用里点菜单栏上的键盘图标选。
4. 没写规则的应用默认不动；想让它们记住你上次用的，在页面最下面把「没写规则的应用」改成「记住上次用的」。

## 已知边界

- **中文输入法里按 ⇧ 切到的英文模式**不是一个输入源：读不到也切不了，规则只能定到「微信输入法」，定不到「微信输入法的英文模式」。
- **不抢前台的浮层**（Spotlight、Alfred、Jarvis 的全局搜索）不算换了应用，不会按规则换。
- **网站规则**（按浏览器当前页换）还没有：要等宿主的「浏览器当前页订阅」（jarvis-mac 总规划 P2）。
- 和 Input Source Pro 这类切换器同时开着会互相改来改去，只留一个。
- 需要 Jarvis ≥ 3.3.2（SDK 2.13：输入源、前台应用、提示与持有订阅即常驻）。
